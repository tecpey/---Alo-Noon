# نقشه راه MVP الو نون

## فاز ۰ — اعتبارسنجی و قرارداد عملیات

- انتخاب منطقه پایلوت بابل
- ارزیابی نانوایی‌ها
- تعریف ۲ تا ۳ محصول تازه امضادار
- تست بسته‌بندی
- توافق SLA و تسویه با مرکز پیک
- اندازه‌گیری مسیر، هزینه و زمان واقعی
- تعریف سیاست لغو، جایگزینی و بازپرداخت

## فاز ۱ — Foundation

- Monorepo و CI
- API versioning و OpenAPI
- PostgreSQL و مدل دامنه
- Identity/RBAC پایه
- City/Zone configuration
- Observability و Audit baseline

## فاز ۲ — Commerce Core

- Catalog و Bakery Offering
- Cart، Quote و Order
- پرداخت و Wallet Ledger
- پنل مشتری پایه
- پنل مدیریت پایه

## فاز ۳ — Operations

- چاپ سفارش نانوایی
- پنل Bakery
- Logistics Provider Adapter
- Dispatch و رهگیری
- اعلان‌ها و خطاهای عملیاتی

## فاز ۴ — CRM و تلفن

- Customer 360
- Household wallet and permissions
- ثبت سفارش تلفنی
- Ticketing و Interaction history
- سناریوهای تماس خروجی و پیگیری

## فاز ۵ — پایلوت محدود

- سفارش واقعی در محدوده کوچک
- سنجش Unit Economics
- کنترل تازگی و کیفیت
- بازبینی قیمت پیک
- رفع خطا و آماده‌سازی توسعه منطقه

## معیار عبور از پایلوت

- نرخ تحویل موفق پایدار
- نرخ لغو و شکایت در محدوده هدف
- اقتصاد هر سفارش قابل دفاع
- کیفیت یکنواخت محصول تازه امضادار
- تسویه قابل تطبیق
- امکان ردیابی کامل هر Incident
