# خط مبنای امنیت و حریم خصوصی

## داده‌های حساس

- شماره تماس و هویت
- آدرس و موقعیت مکانی
- تاریخچه سفارش و رفتار خرید
- اطلاعات خانواده
- تماس‌های ضبط‌شده و متن تماس
- کیف پول و تراکنش‌ها
- داده‌های پیک و نانوایی

## کنترل‌های پایه

- رمزنگاری در انتقال و در حالت ذخیره برای داده‌های حساس
- RBAC و حداقل دسترسی
- جداسازی نقش اپراتور، نانوایی، پیک، Provider و مدیر
- Audit log برای مشاهده و تغییر اطلاعات حساس
- idempotency در پرداخت، کیف پول و وب‌هوک
- عدم ثبت Token، آدرس کامل یا اطلاعات پرداخت در Log عمومی
- مدیریت Secret خارج از Git
- Backup، بازیابی و تست دوره‌ای
- سیاست نگهداری و حذف داده

## کیف پول

- دفترکل append-only
- مرجع و idempotency key یکتا
- تطبیق دوره‌ای
- محدودیت و تأیید عملیات مدیریتی
- عدم اجازه تغییر مستقیم موجودی

## تلفن

ضبط تماس، تبدیل گفتار به متن و نگهداری آن‌ها تنها با سیاست رضایت، دسترسی محدود و دوره نگهداری مشخص فعال می‌شود.
