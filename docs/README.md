یا گفتگو باقی بمانند.

> اسناد شماره‌گذاری‌شده فارسی، زمینه محصول و معماری هدف را توصیف می‌کنند و

> `architecture/` منبع معتبر وضعیت Phase 1 هستند و بخش‌های Implemented، Planned،
