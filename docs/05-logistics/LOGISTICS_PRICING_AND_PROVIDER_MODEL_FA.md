# لجستیک، قیمت‌گذاری و شرکای پیک

## هدف

ارائه قیمت شفاف و زمان تحویل واقع‌بینانه بدون وابستگی به مرکز پیک اولیه بابل.

## اجزای قیمت

- کرایه پایه
- فاصله واقعی مسیر
- زمان تخمینی سفر
- ترافیک
- تقاضای لحظه‌ای و دسترسی پیک
- ساعت و روز
- شرایط دریافت/تحویل
- هزینه مدیریت جریان تازه امضادار
- تخفیف اشتراک یا کمپین

## قواعد

- Quote باید زمان انقضا داشته باشد.
- افزایش قیمت سقف مشخص دارد.
- پس از پرداخت، تغییر مبلغ بدون رضایت مشتری ممنوع است.
- تمام اجزا و نسخه Policy ثبت می‌شوند.
- قیمت مشتری، سهم پیک، سهم Provider و درآمد پلتفرم از هم جدا هستند.

## Provider Adapter

هر شریک لجستیک باید در یک قرارداد مشترک پیاده‌سازی شود:

- quote
- create mission
- assign courier
- track mission
- cancel mission
- delivery proof
- incident report
- webhook validation
- settlement export

در نبود API شریک، پنل Dispatch داخلی به‌عنوان Adapter انسانی عمل می‌کند.

## انتخاب Provider

تصمیم می‌تواند براساس قیمت، ETA، ظرفیت، منطقه، کیفیت، نرخ پذیرش و SLA انجام شود. Failover به شریک دوم باید بدون تغییر Order Model ممکن باشد.
